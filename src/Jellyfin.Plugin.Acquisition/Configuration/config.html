Integración Prowlarr

Integración qBittorrent

El plugin marca cada torrent con una etiqueta «acq-…» para seguirlo. Con esta opción se borran las de descargas ya importadas o canceladas (el torrent se conserva). Las demás etiquetas no se tocan.

Preferencias y Límites de Releases

En modo manual no se envía nada a qBittorrent hasta que eliges una release en «Seleccionar release». En una serie se pide una elección por cada descarga, de una en una.

Apariencia del buscador

Los colores y medidas se pueden ajustar desde el CSS personalizado de Jellyfin con las variables --acquisition-accent, --acquisition-radius, --acquisition-surface y --acquisition-blur. Tras cambiarlo, recarga la página.
